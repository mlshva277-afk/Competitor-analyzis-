# Manrope

Source: `@fontsource-variable/manrope@5.3.0` from registry.npmjs.org.
The npm distribution archive was checked against its published SHA-512 integrity
before extracting these WOFF2 files. License: OFL-1.1, included in LICENSE.

Only Latin, Cyrillic and Cyrillic Extended subsets are retained.
`branding.font_css()` embeds them with their original Unicode ranges and a
variable weight range 200–800. The UI uses Light/Regular/Medium/Semibold weights.
No request to a third-party font server is needed at runtime or in exported HTML.
